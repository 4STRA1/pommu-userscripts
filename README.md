3. Tampermonkeyの画面が出たら「インストール」を押します。

## pommu-input-fix2

Android版Chromeで、投稿画面の入力欄にキーボードを出すと、最初の2〜3行が見えなくなる問題の対策です。

### 問題の原因

入力欄の最低高さ(`min-height: 240px`)が固定されているため、キーボード表示で表示領域が狭くなると、固定ヘッダーとツールバーの間に収まりません。さらに、ブラウザの自動スクロールがstickyヘッダーの高さを考慮しないため、入力欄の上端がヘッダーの裏に入り込みます。ページズームが90%のときに起きて、75%では起きないという報告がありました。

### やっていること

- 画面の上端と下端に張り付いた帯(ヘッダー、ツールバー)の高さを自動で測ります。
- `scroll-padding-top` と `scroll-padding-bottom` を設定し、自動スクロールが帯を避けるようにします。
- 入力欄の最低高さを、帯の間に収まる値まで下げます(最低72px)。
- 入力欄の上端が隠れていたら、ずれた分だけスクロールして戻します。
- 入力欄の親要素の `max-width` を外して、横幅を画面幅いっぱいに広げます。
- SPA遷移で投稿画面に入った場合も処理します。
